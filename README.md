# NukeAccount

Aliucord-плагин: команда `/nuke` — выходит со всех серверов и удаляет всех друзей
через официальный Discord REST API (прямые HTTP-запросы, не через внутренние
обфусцированные классы рендера — поэтому меньше шансов, что что-то сломается
между версиями Discord).

## Почему исходник, а не готовый .zip с classes.dex

Скомпилировать это в classes.dex может только тулчейн с доступом к:
- Android SDK / Gradle
- сборочным jar'ам Aliucord (скачиваются по сети при первой сборке)

У меня в этой сессии нет сетевого доступа и Android build tools, поэтому
собрать бинарник здесь физически нельзя. Сборка на твоей стороне — одна команда.

## Как собрать (5 минут)

1. Склонируй шаблон: https://github.com/Aliucord/plugins-template
   (или используй свой существующий репозиторий плагинов, если уже есть).
2. Создай папку `NukeAccount/` рядом с другими плагинами в шаблоне.
3. Скопируй туда:
   - `manifest.json` (уже с нужными полями)
   - `src/main/java/com/aliucord/plugins/NukeAccount.kt`
4. В `build.gradle.kts` укажи `pluginClassName` как в манифесте
   (`com.aliucord.plugins.NukeAccount`).
5. Подключи телефон по ADB (или эмулятор с Aliucord), выполни:
   ```
   ./gradlew NukeAccount:make
   ./gradlew NukeAccount:deployWithAdb
   ```
6. В Discord: настройки → Aliucord → Plugins → включи NukeAccount.

## Использование

В любом чате набери `/nuke` и отправь. Скрипт:
1. Получает список твоих серверов → выходит из каждого (DELETE-запрос), с паузой ~400мс между запросами.
2. Получает список friend-отношений → удаляет каждое.
3. Кидает toast "Done nuking" по завершении.

## Если что-то не компилируется

`StoreStream.getAuthentication().token` — это стандартное место, откуда токен
берут почти все моды под Discord Android (Aliucord/Vencord и т.д.), но Discord
периодически переименовывает внутренние поля при обновлениях. Если сборка
падает именно на этой строке — открой `base.apk` через jadx, найди класс
`StoreAuthentication` (или похожий) и посмотри актуальное имя геттера токена,
замени в коде.

## Осторожно

- Между guild/relationship запросами стоит `Thread.sleep(400)` — не убирай,
  иначе Discord может временно зарейтлимитить или пометить аккаунт как
  подозрительный при большом количестве серверов/друзей.
- Действие практически необратимо в том смысле, что дружбы придётся
  восстанавливать вручную по одному — сам ты предупреждён, я коммитить не буду.
